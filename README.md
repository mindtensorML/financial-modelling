# Financial Modeling Playbook, version 8

Live map at https://mindtensorml.github.io/financial-modelling/

This map lays out how to build a financial model that holds up in review, in 6 phases, 91 steps and 13 checkpoints, with 5 feedback loops. It runs from scoping and architecture through inputs and assumptions, the three-statement build and DCF, output checks, and stress testing. A separate section handles circular references. It adapts to more than 12 model types.

Built by Caesar Rana, CFA, at SpaceXAI and shared with permission. The map describes a general method and contains no client data. See all the maps at https://mindtensorml.github.io/

The repo also holds the Mermaid source (`Financial_Modeling_Playbook_v8.mermaid`) and a workbook version with one sheet per phase plus an adaptation guide (`Financial_Modeling_Playbook_v8.xlsx`).
