Financial modeling · Build and review · v2.2, October 2026

Financial Modeling Playbook

How to build a financial model that holds up in review, from the decision it serves to an independent check and a signed release.

v2.2, October 2026Mapped against the ICAEW Financial Modelling Code and the FAST Standard 02cA general method with no client data

The map uses a three-statement model and a discounted cash flow as its worked case. The same six phases hold for other model types, and the strip below shows what changes for each. Every step names an owner and cites the standard that speaks to it. Where no standard does, the step is marked as practitioner practice. The tags assume a frontier model in late 2026 can draft formulas, schedules and checks under review. The model owner still signs the assumptions, and a reviewer who did not build the model signs the review.

Who signs

Every task and gate has a named owner role. The decision owner signs the scope. The model owner signs the assumptions and the release. A reviewer who did not build the model signs the review. Where a model drafts, the owner reviews and signs. Where a model runs a step, the owner stays accountable and samples the output. The tags are design estimates of what a frontier model could do under that control. They are not measured results.

Context

Same phases, different engines

The worked case is a corporate valuation. Other model types keep the six phases but swap the calculation engine and the headline outputs. The v1 workbook holds a deep dive for each type.

Structure

Phase 01

Scoping

What good looks likeOne page states the decision, the audience, at most three headline metrics, the horizon, the periodicity, the constraints and what is left out. The decision owner signs it before any formula is written. The model's risk sets how much review it gets.
Standard anchors · ICAEW FMC Model definition and purpose p.3, Error reduction p.14
  1. SC-01Model draftsModel owner

    State the decision in one sentence

    A decision, not a topic. If it takes more than one sentence the scope is too broad. A model can draft it from the mandate. The model owner confirms it with the decision owner.

    Practitioner practice; ICAEW FMC p.3 clear purpose and defined output
  2. SC-02Model draftsModel owner

    Identify the audience and how they will use the model

    A committee needs a clear answer. A deal team needs to drill down. The audience sets the level of detail and documentation.

    Practitioner practice; ICAEW FMC p.3
  3. SC-03Human-onlyModel owner

    Rate the model's risk and set the review level

    How large is the decision, and how bad would an error be? The answer decides between self-review, peer review and an independent model audit. It is set now so the review is budgeted, not squeezed in at the end.

    ICAEW FMC Error reduction p.14
  4. SC-04Model draftsModel owner

    Define at most three headline metrics

    The numbers the decision turns on. Everything else in the model exists to produce them.

    Practitioner practice
  5. SC-05Model draftsModeler

    Set the time horizon

    Long enough to reach a steady state. For project finance, match the contract or asset life.

    Practitioner practice; v1 xlsx 1.4
  6. SC-06Model draftsModeler

    Set the periodicity

    Annual, quarterly or monthly. Use monthly only where cash timing matters, such as construction.

    ICAEW FMC Consistency p.9; v1 xlsx 1.5
  7. SC-07Model draftsModel owner

    List constraints and confirm a spreadsheet is the right tool

    Data access, accounting basis, covenant definitions and tax regime. Ask whether a spreadsheet suits the job at all.

    ICAEW FMC p.3 Principle 4
  8. SC-08Model draftsModel owner

    List exclusions and estimate the impact of each

    Say what the model will not do. For each material exclusion, give a one-line estimate of how much it would move a headline metric.

    Practitioner practice; v1 xlsx 1.7 and 1.11
  9. SC-D1Decision gateModel owner

    Scope complete?

    Decision, metrics, horizon, periodicity, constraints and exclusions are all written down.

    Practitioner practice
  10. SC-09Model draftsModeler

    Write the scope summary

    One page or a section on the cover sheet. Later checks reconcile the finished model back to it.

    Practitioner practice; v1 xlsx 1.8
  11. SC-D2Decision gateDecision owner

    Decision owner signs the scope?

    Explicit agreement on the scope and on the review level set at SC-03 before building starts. The person who bears the decision agrees how hard the model is tested. A short sign-off now saves days of rework. A requested change goes back through the scoping steps it touches and returns here for signature.

    Practitioner practice; v1 xlsx 1.9

Phase 02

Architecture

What good looks likeInputs, calculations and outputs sit in separate sheets or clearly marked sections. Every sheet shares one timeline and one column layout. Timing flags, a checks sheet and a change log exist before the first calculation.
Standard anchors · ICAEW FMC Layout and structure pp.4-5, Clarity pp.10-12, Error reduction p.14; FAST 02c 1.01-01 to 1.02-04
  1. AR-01Model draftsModeler

    Define the sheet map and order

    Group sheets as foundation (inputs, timing), workings, presentation and control (checks, scenarios, change log). Logic flows left to right. Each sheet has one job.

    ICAEW FMC p.4; FAST 02c 1.01-01, 1.02-01
  2. AR-02Model-runModeler

    Name and color-code sheets by function

    Short descriptive names. No Sheet1. Colors or prefixes by function, explained in the model.

    ICAEW FMC p.12
  3. AR-03Model draftsModeler

    Fix one column layout and one timeline for all sheets

    The same period sits in the same column on every sheet. Label, unit and constant columns are fixed too.

    ICAEW FMC p.9; FAST 02c 1.01-02, 1.01-03
  4. AR-04Model-runModeler

    Set the row structure, labels and units

    Logical blocks with headers. Every row has a label and a unit, including whether money is real or nominal. Opening and closing balances are labeled as such.

    ICAEW FMC p.11; FAST 02c 3.05-04, 3.05-11
  5. AR-05Model draftsModel owner

    Choose and document the sign convention

    Either normally positive in workings with inflows positive and outflows negative on presentation sheets, or one rule throughout. Label each row. Never use debit and credit signs. Make every sign flip visible.

    ICAEW FMC p.12; FAST 02c 1.01-08, 1.01-09, 3.04-04
  6. AR-06Model draftsModeler

    Set the formatting key

    Mark inputs with a fill color or border, not font color alone. Use styles. Put a formatting key in the model. v1's blue font for inputs clashes with FAST's blue font for imports, so state which key applies.

    ICAEW FMC pp.5, 10; FAST 02c 1.01-06
  7. AR-07Model draftsModeler

    Map the calculation flow and draw a model map

    A diagram of which sheet feeds which. It becomes the reviewer's guide and the debugging map.

    ICAEW FMC p.5; FAST 02c 1.02-01
  8. AR-08Model-runModeler

    Build the timing and flags sheet

    Period dates and counters, phase flags, event flags and partial-period factors. Formulas multiply by a flag instead of nesting IF tests.

    ICAEW FMC p.16; FAST 02c 1.02-03, 3.07-01
  9. AR-09Model draftsModeler

    Set up the checks sheet and master check

    Checks are planned from the outset, not added at the end. Integrity checks and commercial alerts are kept apart. The master check shows in the frozen pane of every sheet.

    ICAEW FMC pp.14-15; FAST 02c 2.03-05 and glossary
  10. AR-10Model draftsModeler

    Flag likely circular references

    Interest on average debt, fees on total funding, reserve accounts sized on debt service and tax on interest are the usual loops. List each one and the preferred method. The circular references subprocess resolves each loop when it is built.

    ICAEW FMC p.18; FAST 02c 1.01-11
  11. AR-11Model draftsModel owner

    Set version control and a change log

    One workbook, not a chain of linked files. File naming with version and date. A change log sheet records date, author, version, sheets affected, what changed and why.

    ICAEW FMC pp.3-4; FAST 02c 1.01-01, 1.03-01
  12. AR-12Model draftsModeler

    Plan the contents page and user guide sheet

    A contents page with links and a user guide inside the workbook, never in a separate email.

    ICAEW FMC pp.5-6
  13. AR-D1Decision gateModel owner

    Architecture fit for purpose?

    Sheet map, timeline, sign convention, formatting key, checks sheet and change log are in place.

    ICAEW FMC p.3

Phase 03

Inputs and Assumptions

What good looks likeEvery input has one home, a source and a range. Actuals and forecasts are kept apart. Tax and regulatory inputs are checked against the law in force at the model date. The model owner signs the assumptions, not the model that drafted them.
Standard anchors · ICAEW FMC Make inputs easy to find p.5, Avoid duplication p.6, Separate forecast data p.7, Avoid hardcoding p.17; Croll s4
  1. IN-01Model draftsModel owner

    Gather source documents and open a data book

    Filings, management accounts, contracts and term sheets, each logged with a reference. The model owner first confirms that the data-use terms allow a model to read any confidential material. A model can then log each document.

    Practitioner practice; Croll s4; v1 xlsx 3.1
  2. IN-02Model-runModeler

    Enter historical financial statements

    Three to five years from the source documents, each figure tagged with its page. Totals tie to the filed totals.

    Practitioner practice; v1 xlsx 3.2
  3. IN-03Model draftsModeler

    Cross-check the historical data

    Balance sheet balances in every year. Net income and cash tie across statements. A model can run the ties. The modeler reviews every break and spot-checks key lines against the source, since a model should not be the only check on its own transcription.

    Croll s4; v1 xlsx 3.8
  4. IN-04Model draftsModeler

    Document every data adjustment

    Reclassifications, one-off items and normalizations, with the reason for each.

    Practitioner practice; v1 xlsx 3.9
  5. IN-05Model-runModeler

    Calculate historical ratios and growth

    Growth, margins, working capital days, capital spending and tax rates, as formulas on the historical data.

    Practitioner practice; v1 xlsx 3.3
  6. IN-06Model-runModeler

    Build the input sheets

    One location per input, grouped by topic. Forecast and actual data in separate areas. Data validation where an input has limits. No constants inside formulas.

    ICAEW FMC pp.5-7, p.15, p.17
  7. IN-07Model-runModeler

    Separate macro inputs from operating inputs

    Inflation, interest rate benchmarks, exchange rates and GDP on their own sheet, used by every other sheet.

    FAST 02c 1.01-01; v1 xlsx 3.12
  8. IN-08Model-runModeler

    Build the inflation index

    Base year 100, compounding by period. Escalate nominal values by the index and convert to real by dividing by it.

    FAST 02c 1.01-01, 2.02-06; v1 xlsx 3.13
  9. IN-09Model draftsModel owner

    Handle currencies explicitly

    Every row states its currency. Project each exchange rate and convert at the projected rate. The forecasting method is a judgment for the owner.

    ICAEW FMC p.11; v1 xlsx 3.14
  10. IN-10Model draftsModel owner

    Source and justify each assumption

    Keep an assumption register. Each entry records its source, rationale and owner, the date it was last checked and the change since the last version. A model can draft the support and find benchmarks. The model owner judges whether each one is defensible.

    Croll s4; Practitioner practice
  11. IN-11Model draftsModel owner

    Set low, base and high ranges and test the base case against them

    A range for each key driver. The base case must sit inside its own cited range, or the gap is explained.

    Practitioner practice; v1 xlsx 3.6 and 3.15
  12. IN-12Model-runModeler

    Build the scenario selector

    One switch that moves the whole model between named scenarios. Scenario values sit side by side on the input sheet.

    ICAEW FMC p.3; FAST 02c 1.01-01
  13. IN-D1Decision gateModeler

    Historical data and input sheets pass?

    Historicals balance, every input is sourced, the selector works, and no number sits outside the input sheets.

    ICAEW FMC p.14
  14. IN-13Model draftsTax adviser

    Verify tax and regulatory inputs against current law

    Rates, loss rules, depreciation and credits change. Check primary sources at the model date, and record the rule, its effective date and when it was checked. v1's examples were US-specific and some are now out of date.

    Practitioner practice; Croll s4
  15. IN-D2Decision gateModel owner

    Model owner signs the assumptions book?

    The owner reviews every key assumption, its source and its range, and signs. A frontier model can draft the book but cannot own it.

    Practitioner practice

Phase 04

Build

What good looks likeBuild one block at a time and test as you go. The income statement is checked before the balance sheet is built. Schedules come before the lines that use them, so depreciation and interest exist before EBIT and net income. The balance sheet can only balance once closing cash links back from the cash flow, so the cash tie and the balance check close the three statements. A frontier model can draft most formulas. The value is in the checks that prove them, and in the owner's judgment on discount rates and terminal value. Not every model needs a DCF. Once the balance sheet balances, a gate sends a project finance model to its cash flow waterfall. A model with another engine or no valuation block goes on to outputs.
Standard anchors · ICAEW FMC Consistency p.8, Calculation techniques pp.16-17; FAST 02c 1.01-07; Croll s4
  1. BD-01Model-runModeler

    Build the operating drivers

    Where revenue is volume times price, model volumes, capacity and prices by segment before any financial line.

    v1 xlsx 4.24 and 4.26; ICAEW FMC p.16
  2. BD-02Model-runModeler

    Build the revenue line

    Linked to drivers or growth inputs, never a typed number. One consistent formula across the row.

    Practitioner practice; v1 xlsx 4.1
  3. BD-03Model-runModeler

    Build cost of sales and gross profit

    Driven by revenue and the margin input.

    Practitioner practice; v1 xlsx 4.2
  4. BD-04Model-runModeler

    Build operating costs by driver

    Each cost on its own driver, such as share of revenue, fixed plus inflation, or unit cost times volume.

    Practitioner practice; v1 xlsx 4.3 and 4.27
  5. BD-05Model-runModeler

    Build the fixed asset roll-forward

    Opening plus additions less depreciation equals closing. Assets never depreciate below zero.

    v1 xlsx 4.7 and 4.28; Croll s4
  6. BD-06Model-runModeler

    Calculate EBITDA and EBIT

    Pure formula rows. Compare margins with history.

    Practitioner practice; v1 xlsx 4.4
  7. BD-07Model draftsModeler

    Build the debt schedule

    One schedule per instrument, with drawdowns, interest, repayments and grace periods. Debt amortizes to zero or the refinancing is shown. A model can draft the schedule from the term sheet. The modeler checks each term against the document, because lenders will test the model on it.

    v1 xlsx 4.8 and 4.30; Croll s4
  8. BD-08Model draftsModeler

    Calculate interest, tax and net income

    Interest per the method planned at AR-10. If an interest loop is built here, it goes to the circular references subprocess. Tax on taxable profit, with losses carried forward and any limit on interest deductions. A model can draft the tax logic. The tax adviser reviews it.

    Croll s4; v1 xlsx 4.5
  9. BD-D1Decision gateModeler

    Income statement check passes?

    Margins are within history or explained, and no formula errors show.

    ICAEW FMC p.14
  10. BD-09Model-runModeler

    Build working capital

    Receivables, inventory and payables from days inputs.

    Practitioner practice; v1 xlsx 4.6
  11. BD-10Model-runModeler

    Build retained earnings and equity

    Retained earnings flow from net income less dividends.

    v1 xlsx 4.9; Croll s4
  12. BD-11Model-runModeler

    Assemble the balance sheet

    Combine the schedules and add the balance check row. The cash line waits for closing cash from BD-15. It is never a plug, so the balance check runs only after the cash flow is built.

    Practitioner practice; v1 xlsx 4.10
  13. BD-12Model-runModeler

    Build cash from operations

    Net income, non-cash items and working capital changes, linked to the balance sheet lines.

    Practitioner practice; v1 xlsx 4.11
  14. BD-13Model-runModeler

    Build cash from investing

    Linked to the asset schedule, never re-entered.

    v1 xlsx 4.12; FAST 02c 1.01-07
  15. BD-14Model-runModeler

    Build cash from financing

    Linked to the debt and equity schedules.

    Practitioner practice; v1 xlsx 4.13
  16. BD-15Model-runModeler

    Calculate closing cash

    Opening cash plus the three flows. Link closing cash to the cash line on the balance sheet. Cash sweeps and reserve accounts sized on debt service close their loops here, so any such loop goes to the circular references subprocess now.

    Practitioner practice; v1 xlsx 4.14
  17. BD-D3Decision gateModeler

    Cash ties to the balance sheet?

    Closing cash in the cash flow equals cash on the balance sheet in every period. The check row decides pass or fail. A failure means the cash link or a cash flow line is wrong. Once cash ties, the balance check runs next.

    ICAEW FMC p.14
  18. BD-D2Decision gateModeler

    Balance sheet balances in every period?

    It runs once closing cash links back from the cash flow, since cash is never a plug. Assets less liabilities less equity is zero within the set tolerance. The check row decides pass or fail, and no one overrides it. If it fails, quantify the gap by period. A gap that matches a balance sheet movement the cash flow missed goes back to the cash flow build. A gap inside the fixed asset, debt, tax, working capital or equity schedules goes back to the schedules.

    ICAEW FMC p.14; Croll s4
  19. BD-16Model-runModeler

    Calculate unlevered free cash flow

    After-tax operating profit plus non-cash charges less capital spending and working capital investment.

    Practitioner practice; v1 xlsx 4.15
  20. BD-17Model draftsModel owner

    Build the discount rate

    A model can assemble the cost of capital. Beta, equity risk premium and target capital structure are judgments. They sit on the input sheet with their sources, so the owner signs them with the assumptions book at IN-D2.

    Practitioner practice; v1 xlsx 4.16
  21. BD-18Model-runModeler

    Discount the cash flows

    State the timing convention, end of period or mid-period, in the user guide.

    v1 xlsx 4.17; ICAEW FMC p.6
  22. BD-19Model draftsModel owner

    Calculate terminal value by two methods

    Perpetuity growth and exit multiple. Growth stays below the discount rate. Report the terminal share of total value.

    Practitioner practice; v1 xlsx 4.18
  23. BD-D4Decision gateModel owner

    Terminal value methods reconcile?

    v1 used a 20 percent gap as the trigger to investigate. A larger gap means the growth rate or the multiple needs another look.

    Practitioner practice
  24. BD-D5Decision gateModel owner

    Which output block does the scope call for?

    The signed scope names the headline metrics. A corporate valuation goes on to the DCF block. A project finance model builds its cash flow waterfall instead. Any other model goes on to outputs. A bank or insurer model with no valuation block needs nothing more here. An engine the map does not draw, such as LBO returns or bank capital ratios, is built first from the model types strip and its deep dive in the v1 workbook. It then faces the same output checks.

    Practitioner practice
  25. BD-21Model draftsModeler

    Build the project finance cash flow waterfall and cover ratios

    Cash flow available for debt service, or CFADS, is revenue less operating costs, tax and maintenance capital spending, adjusted for working capital, before any financing flow. It pays senior interest and scheduled principal first. Reserve accounts such as the debt service reserve are topped up next, then any junior debt is served. Distributions come last, and only if the lock-up test passes. The term sheet sets the exact order and the reserve sizes. Distributions link back to the equity schedule at BD-10. DSCR is CFADS for a period divided by the senior debt service due in that period. LLCR is the present value of CFADS over the remaining loan life, discounted at the cost of the debt, divided by the senior debt outstanding at the test date. Some term sheets add the debt service reserve balance to that present value. Equity IRR runs on equity injected and distributions received. Sources equal uses at the end of construction, and debt drawn never exceeds the commitment. A model can draft the waterfall from the term sheet. The modeler checks each step against the document. The balance and cash ties are proven again at OC-05 and OC-06.

    Practitioner practice; Croll s4
  26. BD-20Model draftsModel owner

    Bridge enterprise value to equity value

    Deduct net debt and debt-like items such as leases, pensions and minority interests. Use diluted shares. The list of debt-like items is a judgment.

    Practitioner practice; v1 xlsx 4.19

Phase 05

Outputs and Checks

What good looks likeA dashboard answers the scoped question and every number on it traces to one calculation. Integrity checks should never fail in any scenario. Alerts flag commercial points such as a covenant breach. The master check is proven to catch a planted error.
Standard anchors · ICAEW FMC Include checks p.14, Include a master check p.15, Layout p.4; FAST 02c 2.03-05 and glossary; BDO FMAS p.5
  1. OC-01Model-runModeler

    Build the output summary

    The scoped metrics, the valuation or returns summary and the key inputs on one sheet.

    ICAEW FMC p.4
  2. OC-02Model draftsModel owner

    Show the valuation range

    Methods and scenarios side by side, so the decision owner sees a range, not a point. Choice of peers and precedents is a judgment.

    Practitioner practice; v1 xlsx 5.2
  3. OC-03Model-runModeler

    Show the key ratios

    Multiples and returns that put the value in context.

    Practitioner practice; v1 xlsx 5.3
  4. OC-04Model-runModeler

    Complete the checks sheet

    Every check planned at AR-09 is live, with a tolerance scaled to the model's units.

    ICAEW FMC p.14; FAST 02c glossary
  5. OC-05Model-runModeler

    Balance check

    Every period, within tolerance.

    ICAEW FMC p.14; Croll s4
  6. OC-06Model-runModeler

    Cash tie check

    Cash flow closing cash against the balance sheet, every period.

    ICAEW FMC p.14
  7. OC-07Model-runModeler

    Net income and retained earnings tie checks

    Income statement net income against the start of the cash flow. Closing retained earnings equal the opening balance plus net income less dividends.

    ICAEW FMC p.14; Croll s4
  8. OC-08Model draftsModel owner

    Reasonableness alerts

    Revenue positive, margins in range, growth below the discount rate. These are alerts, not integrity checks. The ranges are the owner's call.

    FAST 02c glossary; BDO FMAS p.5
  9. OC-09Model-runModeler

    Master check, coverage test and break test

    One cell sums every check and shows in every frozen pane. Confirm it covers every check row. Plant an imbalance, a zero revenue and a negative cash balance, and confirm each one trips it.

    ICAEW FMC p.15; FAST 02c 2.03-05; Practitioner practice
  10. OC-D1Decision gateModeler

    Integrity checks pass and the break test trips?

    All integrity checks pass, and the master check catches each planted error.

    ICAEW FMC p.15
  11. OC-10Model draftsModel owner

    Build commercial alerts

    Negative distributable cash, coverage or leverage cliffs, and tax or regulatory inputs outside legal bounds. Each one flagged and explained.

    FAST 02c glossary; v1 xlsx 5.11 to 5.13
  12. OC-11Model-runModeler

    Build the dashboard with live checks

    Five to eight headline numbers, the financing summary and the three to five checks that would invalidate the model. Every value is a formula.

    ICAEW FMC p.4; v1 xlsx 5.14 and 5.15
  13. OC-12Model-runModeler

    Trace every dashboard number to its source

    Follow each cell to its source calculation. No hardcodes, no stale links, no summary of a summary. A model can do this cell by cell and log what it found.

    ICAEW FMC p.16; FAST 02c 1.01-07; v1 xlsx 5.16
  14. OC-D2Decision gateModel owner

    Dashboard traced and alerts explained?

    Every dashboard cell traces to source and every alert has an explanation.

    Practitioner practice

Phase 06

Stress, Review and Release

What good looks likeSensitivities, scenarios and a combined downside are run on the checked model. The builder's own reconciliation comes first. Then a reviewer who did not build the model tests it to the depth set at scoping. The model owner signs the release of one identified version.
Standard anchors · ICAEW FMC Review and test your models p.14, Include user guidance p.6, Calculation techniques p.16; Croll s2 to s6; BDO FMAS pp.4-5; EuSpRIG
  1. ST-01Model-runModeler

    Build two-way sensitivity tables and prove they are wired

    The two drivers that matter most, such as discount rate and terminal growth. Put the base case at the center of each grid. The center cell must equal the live base case, which proves the table drives the inputs the model actually uses. Each other cell should differ from its neighbors and move the way the modeler expected. If the model uses a copy-paste macro for a loop, the tables must re-run it for each case.

    ICAEW FMC p.3, p.14; Croll s5; Practitioner practice
  2. ST-02Model-runModeler

    Build one-way sensitivities and a tornado chart

    The top five to seven drivers one at a time, ranked by impact.

    Croll s5; v1 xlsx 6.2
  3. ST-03Model-runModeler

    Run and record the scenarios

    Low, base and high from the selector, with key outputs saved for each.

    Croll s5; v1 xlsx 6.3
  4. ST-04Model-runModeler

    Verify sensitivity labels and directions

    An upside must sit above the base case. Units must match. A mislabeled sensitivity tells the reader the opposite of the truth.

    Practitioner practice; v1 xlsx 6.10
  5. ST-05Model draftsModeler

    Record expectations, then test extreme values

  14. ST-12Human-onlyIndependent reviewer

    Independent review or model audit

    A reviewer who did not build the model. The depth follows the risk set at SC-03. For a lender model it covers every unique formula and any macro code, consistency with term sheets and contracts, tax and accounting, and sensitivities. The reviewer recomputes the headline returns, such as IRR and the money multiple, and any waterfall from the model's own cash flows, and lists every input with no source. A frontier model can run diagnostics and re-perform calculations for the reviewer. The opinion is the reviewer's own.

Circular References

What good looks likeAvoid the loop if you can. Solve it with algebra if you can. Use a copy-paste macro with a check that the pasted values are current. Iterative calculation is the last resort, and FAST says never release a model that relies on it. The subprocess returns to the build step that called it.
Standard anchors · ICAEW FMC Avoid circular references p.18; FAST 02c 1.01-11, 1.02-01, 3.03-11; MS Excel
  1. CR-01Model-runModeler

    Identify the loop and why it exists

    Trace the chain, such as interest to net income to cash to debt to interest. A model can map precedents and dependents to find it.

    FAST 02c 1.02-01; ICAEW FMC p.18
  2. CR-D1Decision gateModel owner

    How will this loop be handled?

    Choose in this order of preference. Avoid it, solve it, use a macro, and only then iterate.

    ICAEW FMC p.18; FAST 02c 1.01-11
  3. CR-02Model draftsModeler

    Avoid it with a simplifying assumption

    Interest on the opening balance, or a one-period lag. A model can measure how far the result moves. The modeler documents the approximation and its size for the model owner to accept at CR-D3.

    ICAEW FMC p.18
  4. CR-03Model draftsModeler

    Solve it algebraically

    Many loops have a closed form. Interest on an average balance, or fees on total funding, can be solved directly. A model can derive the formula. The modeler checks it against a numerical result.

    ICAEW FMC p.18
  5. CR-04Model draftsModeler

    Use a copy-paste macro with a staleness check

    The macro pastes values to break the loop. A check shows when pasted values no longer match the live result. Sensitivities must re-run the macro. Document the code.

    ICAEW FMC p.13, p.18, p.19
  6. CR-05Model draftsModeler

    Use iterative calculation with a breaker switch

    Last resort. It hides any new, unintended circularity. In Excel desktop the setting affects all open workbooks. Excel's default stops at 100 iterations or a change below 0.001 in the model's own units. An error inside the loop can lock in until the breaker is switched off.

    ICAEW FMC p.18; MS Excel; FAST 02c 1.01-11, 3.03-11
  7. CR-06Model-runModeler

    Test convergence and the breaker

    Change an input, recalculate, change it back and confirm the original answer returns. Compare with the non-circular approximation.

    FAST 02c 1.01-11; v1 xlsx 7.7
  8. CR-D2Decision gateModeler

    Stable and consistent with the cross-check?

    The same answer on every recalculation and within tolerance of the cross-check.

    FAST 02c 1.01-11
  9. CR-D3Decision gateModel owner

    Model owner accepts the approximation?

    The owner accepts the size of the approximation, and the acceptance is recorded in the change log with the amount it moves each headline metric. If it moves a result too far, choose another method.

    Practitioner practice; ICAEW FMC p.18

    Document the method in the user guide

    Which cells form the loop, the method, any switch or macro, and any setting a user needs.

What good looks likeChanges arrive during the build and after release. Each one is logged, sized and routed back to the earliest phase it touches. Everything downstream is then checked again, and a reviewed model is re-reviewed where it changed.

For reviewers

Open questions for practitioners

The map follows the published standards where they speak. Some choices rest on judgment. These are the ones where heads of modeling and model auditors can improve it most.

  1. Where should the line sit between peer review and an independent model audit?

    SC-03 asks the owner to rate model risk. A firm-wide rule, by deal size or by use in a binding document, may serve reviewers better than case-by-case judgment.

  2. Is iterative calculation ever acceptable in a released model?

    FAST says never. ICAEW says disable it. Many corporate and lender models still ship with it switched on. Is a breaker switch plus a convergence test enough in practice?

  3. Which build steps should a frontier model never draft, even with a person signing?

    The current split is 2 human-only, 43 model drafts and 42 model-run. The discount rate, terminal value and the equity bridge are tagged as model drafts with owner sign-off.

  4. Should the master check also cover alerts?

    FAST keeps integrity checks and commercial alerts apart. Some reviewers want one indicator a committee cannot miss. Which works better in front of a committee?
